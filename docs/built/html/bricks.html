Bricks

The Bricks tab has a row for each brick of the project: its icon, grey while it is stopped; its name; its kind and what matters about it, as Wire · sw1 ↔︎ sw2; its state; a button that starts or stops it; and the button of its menu.

The states

Running, Stopped

Its program runs, or not.

Starting

Its program runs once the bricks it plugs into run, and a virtual machine has its disks ready. Meanwhile it counts as running: you can't rename it or delete it, nor quit Virtualbricks.

Not connected

A plug of the brick goes nowhere, as a wire with a free end: it can't start until you connect it.

Not configured

A setting that it needs is missing, as the host of a tunnel client: it can't start until you set it.

Error
A switch wrapper whose folder has no switch to plug into, though the folder is there: it has no socket ctl, or the one that a killed switch leaves. The tooltip of the state says what is wrong, and so does the Logs window. It runs again once a switch listens there.

Above the list

New Brick adds a brick; see The kinds of brick. The search field finds a brick by name or by kind: press Ctrl+F, or start typing in the list. All and Running switch between all the bricks and only those that run, which then show the number of their process. Start All starts every brick that can start, and Stop All stops them.

Starting and stopping

The button of a row starts the brick, or stops it. Starting a brick starts first the bricks it plugs into. Stopping a virtual machine asks its system to shut down. Stopping a brick that is starting calls its start off: its program doesn't run, and the bricks it plugs into start all the same.

The settings of a brick

Double-click a row, or select it and press Enter: the settings of the brick show in place of the list, under a line that names it. OK applies them, and is greyed while a setting is wrong, with the first problem beside it. Cancel and Esc go back to the list without a change. While the brick runs, a bar over its settings says which of them change at once.

The menu of a brick

The button at the end of the row, the right button of the mouse, the Menu key and the picture of the Topology tab open the same menu:

Start, Stop

As the button of the row.

Configure…

The settings of the brick; Enter in the list.

Rename…, Delete…

Greyed while the brick runs or starts; F2 and Delete in the list. Before a brick goes, the dialog says what goes with it: the bricks plugged into it are unplugged, the events no longer start or stop it, and the private copies of a machine go to the trash.

Duplicate

A copy of the brick, with its links, named after it with the next free number. The network cards of a machine get new MAC addresses.

Connect To

The bricks that this one can plug into. Dragging the row of a brick onto the row of another does the same: when one of the two can plug into the other, that row is framed, and they connect when you let go.

When It Starts, When It Stops

An event to run when the brick starts or stops; see Events.

Resume

For a virtual machine, start it from the state that Suspend saved in its first disk.

Process

For a running brick, what to do with its process: Open Control Monitor, which opens the console of the brick in a terminal; Pause and Continue; Suspend and Reset for a virtual machine; Restart; Terminate and Kill, when it doesn't stop.
