Capture interfaces

A capture interface joins a switch of the lab to a network interface that this computer has already, as its Ethernet card: the packets of that interface go into the switch, and those of the switch go out of the interface. It runs vde_pcapplug as root, through sudo; see A tap or a capture interface doesn't start.

Connection

Plugged into

The switch that gets the packets. In Nothing the capture interface is Not connected, and can't start.

Capture

Interface

The interface of this computer, as eth0; None by default. The menu lists the interfaces of this computer when the settings open, but the loopback, lo. Without one the capture interface is Not configured, and can't start. An interface that this computer doesn't have, as in a project made on another computer, shows as eth1, not on this host, with a warning: choose one of this computer.

While it runs

The settings take effect when the capture interface starts again; Restart, under Process in its menu, does it at once.
