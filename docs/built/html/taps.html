Taps

A tap is a network interface of this computer, plugged into a switch of the lab: through it this computer joins the lab, as one more machine on that switch. The interface takes the name of the brick, as tap1, so the name of a tap has 15 characters at most. It runs vde_plug2tap as root, through sudo; see A tap or a capture interface doesn't start.

Connection

Plugged into

The switch that the interface joins. In Nothing the tap is Not connected, and can't start.

Address

Address

How the interface gets its address: Off, the default, DHCP or Manual.

IP address, Netmask, Gateway

With Manual: the address of the interface, 10.0.0.1 by default; its netmask, 255.255.255.0 by default; and the default gateway, empty for none. They are greyed otherwise.

Virtualbricks doesn't give the interface its address yet: with DHCP or Manual, the settings keep your choice, and the line under Address says so. The interface comes up without an address. An event of the start of the tap can give it one; see The address of a tap.

While it runs

A new switch takes effect when the tap starts again; Restart, under Process in its menu, does it at once.
