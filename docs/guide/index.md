# [Virtualbricks]{.app} Help

[Virtualbricks]{.app} makes labs of virtual machines and of the switches,
cables, taps and tunnels between them, and runs them on this computer.

Press [F1]{.key} in a window for the page about it. The settings of a brick, an
event or a disk image, and the **Settings** window, have a **Help** button too.
